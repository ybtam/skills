# Use a baseline Changesets release workflow skill

The collection will include `release-with-changesets` as a portable baseline skill, rather than an optional specialized skill, in baseline version `0.2.0`. `setup-repo`, `adopt-standards`, `upgrade-standards`, and `migrate-to-monorepo` evaluate it after inspection. It configures release CI only after the target owner confirms release intent, release topology, publication choices, release ownership, release safety rules, release branch, release channel, release notes, and authentication. Changesets release CI has proved useful across JavaScript and Python repositories; a Python repository may use a repository-owned `package.json` sidecar for release coordination, but the skill must not claim that Changesets manages Python metadata or artifacts.
